# 文档入口

需要解释观测、核对适用条件或查找缺失依据时，先读[华为云主题指引](huaweicloud.md)。已知命令及条件时直接使用契约，不先读文档。

- 主题未覆盖时，在[全量元数据索引](catalog.jsonl)按标题、文档 ID 或关键词搜索，只读取命中条目；不要加载整库。每行仅含 id、title、section、url。
- 索引来自 2026-10-21 归档：故障排除 190 条、常见问题 251 条。日期表示来源快照，不表示链接当前可用或内容仍适用于目标版本。
- 补充来源：2026-10-22 核验的 18 条官方指引。核验范围为网页标题与正文；按需复核当前内容。
- 格式：优先读页面或 llms.txt 提供的 Markdown（`.md`）；未取得正文时读同文档 HTML（`.html`）。核对文档 ID、标题和正文；不因后缀或 HTTP 200 判定成功。验证页、登录页和空壳不算正文；两种格式共用一个条目。
- 用条目的官方 URL 按需读取原文，核对产品、OS、版本及场景，记录实际读取日期。文档提供候选原因与规则，不能代替当前目标的日志、指标或命令结果。
- 链接失效时按标题或文档 ID 在同一官方来源定位；未找到就说明缺口。网络不可用且已配置本地归档时，可读同 ID 快照并标明日期；缺少归档不阻塞其他证据查询。
- 原文和图片不随技能分发，本地归档路径由执行环境提供，不依赖某台机器的绝对路径。必要的缓存与读取记录放在技能外。
- 新原文与契约冲突时保留版本和差异，复核受影响操作后再使用；不静默覆盖已验证命令。文档中的安装、调参、修复或重启不构成执行授权。

需要实际执行时回到[命令地图](../commands/index.md)；输入衔接读 [Helper](../helpers.md)。
