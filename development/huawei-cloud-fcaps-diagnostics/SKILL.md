# 华为云 FCAPS 诊断

目标：取得问题所需的观测，说明已确认的边界和证据缺口。

## 安全规则

- **默认只读，限定已授权目标。** 按实际行为判断影响，不凭命令名或 HTTP 方法判断只读。
- **禁止擅自探测、采样、扫描、安装或修改。** 先核对影响与授权；已有明确授权和任务直接复用。
- **安全传参，保护凭据。** 使用参数数组或逐个参数转义；禁止 `eval`、拼接未验证文本和选项注入。凭据不写入脚本或报告。
- **限定采样、轮询和重试的结束条件。** 按错误类别处理；权限或参数问题未解决前，禁止原样重试。

## 反幻觉规则

- **核对目标与时间范围。** 云侧核对账号、区域、资源；主机核对目标系统；集群核对 context、命名空间和对象身份。管理机系统不能代替目标系统。
- **只用有依据的资源标识、参数、字段和依赖。** 首次查操作帮助；有效信息直接复用，工具升级、参数报错或输出变化后重查。
- **核对退出状态、错误、目标和结果字段；异步任务须查最终状态。** 无记录、无权限、工具缺失、结果不全和未执行分别说明。
- **禁止把假设、旧记录、文档或帮助核验当作本次实测成功。** 分清证据来源；文档中的操作不代表已获授权。

## 易错点

- **缺数不等于不存在、空闲或正常。** 先核对权限、过滤范围、时间范围和采集条件。
- **比较前对齐对象、时间、单位和统计口径。** 说明分页、采样或截断范围；禁止以局部结果代表全部。
- **禁止把观测直接当作根因。** 先核对契约的适用条件和解释依据；依据不足才按[文档指引](references/documents/index.md)补证据，仍不足则保留假设。
- **输入先解析，不猜默认值；`—` 不表示无必填参数。** 已知命令按完整 ID 搜索 `references/commands/`，缺输入才读[依赖说明](references/helpers.md)。

## 按需读取

- 已知问题：按 [FCAPS 地图](references/commands/index.md) 选择类别和环境；目标不明时读[分诊](references/triage.md)。
- 切换工具或环境时，只读对应工具入口；远程主机执行时读[通道](references/execution.md)。
- 判断实测范围时按 ID 读[验证摘要](references/verification/index.md)。结果按[报告字段](references/report.md)记录。场景配方仅为规划。
