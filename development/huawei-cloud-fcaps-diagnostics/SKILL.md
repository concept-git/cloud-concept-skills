# 华为云故障诊断

以当前证据缩小问题范围，选择能够区分候选原因的下一项检查。

## 诊断原则

先明确目标、时间窗和预期行为，再区分事实、假设与证据缺口。
每项检查应回答一个具体问题；根据观测更新判断，避免重复执行不能增加信息的检查。
核对执行状态、对象及结果范围；无记录或无法查询时保留未知。
历史案例与文档用于提出假设，原因确认和恢复判断依赖当前目标的证据。

默认只读，限定授权范围。探测、采样与变更按实际影响核对授权，已有授权直接复用。
缺少执行通道时记录受阻；凭据不进入报告。

## 知识与工具

- 现象不明时读[分诊](references/triage.md)，已有场景时按[场景索引](references/recipes/index.md)选取指引。
- 执行检查时按[命令地图](references/commands/index.md)读取契约及对应工具要求；缺输入时读[依赖说明](references/helpers.md)。
- 特殊案例或版本差异按[知识外挂入口](knowledge/README.md)检索，核对适用条件及来源。
- 解释依据不足时读[文档指引](references/documents/index.md)。

按当前问题逐步加载；已知路径或命令 ID 可直接定位。

## 完成条件

结论能追溯到证据，并说明适用范围；未确认事项给出缺口和下一项检查。
恢复结论须有恢复后的验证结果；未执行的方案只作为建议。
