# 开通前核验与失败处理

允许的写操作见 `commands.md`。本文件解释检查条件，具体命令参数以当前 `hcloud <Service> <Operation> --help` 为准；帮助报错、操作不存在或参数定义缺失时停止。

## 三类证据分别说明什么

- BSS 目录匹配：找到了目标服务、资源类型、区域和计费方式下的报价规格。
- BSS 询价成功：当前输入得到了价格；容量、单位及包含的计费项仍须匹配实际方案。
- 服务侧核验：检查目标配置的售卖状态、计费支持、账号限制及依赖兼容性。检查通过可说明“当前可用性检查通过”，不能保证服务端一定创建成功。

报价规格编码与创建接口的规格 ID 分别保存并核对映射，不靠拼接或删除后缀替代服务侧查询。

## ECS 的只读核验

先查 `ECS/ListFlavors` 的当前帮助，再按目标规格和 AZ 查询，保留 `id`、CPU、内存和相关 `os_extra_specs`。

1. **售卖状态。** 目标 AZ 在 `cond:operation:az` 中有配置时，以该项为准；否则使用区域级 `cond:operation:status`。`normal/promotion` 表示正常商用，`abandon` 为下线，`sellout` 为售罄，`obt/obt_sellout` 涉及公测。按官方定义处理缺省值，不能只看到区域级 `abandon` 就否定 AZ 的 `normal`。
2. **计费支持。** 查看 `cond:operation:charge`；`period` 对应包周期，`demand` 对应按需，官方约定未配置时两者均支持。若需要销售策略补充证据，可在当前 help 和响应支持的范围内调用 `ListFlavorSellPolicies`，核对实际返回的规格、AZ、`sell_mode` 和 `sell_status`；不可因 CLI 枚举存在就认定服务端支持所有模式。
3. **账号与依赖。** 核对公测／角色限制、可查配额、镜像架构和状态、网络与子网约束、磁盘类型等。查询网络或镜像时保留判断兼容性所需字段，不能只保留名称。

存在明确不支持、售罄或权限限制时停止。当前只读接口无法证明的条件应如实说明，不据此宣称“有货”。其他服务用自身的产品或规格查询接口，不套用 ECS 的字段规则。

依据：[ECS 规格扩展字段](https://support.huaweicloud.com/api-ecs/zh-cn_topic_0020212656.html)。字段含义按官方定义解释，实际状态以当前响应为准。

## 费用和请求检查

费用分为三种状态：本次完整配置已可靠询价；费用待核实；动作本身有依据证明不独立收费。关联资源的费用也需说明。费用待核实时先告知“价格未知且可能收费”，取得额外同意；不能因此跳过已知的不兼容或权限限制。

全局参数是 `--dryrun`：只构造本地请求，不访问业务接口。它不能验证库存、权限或下单是否成功。部分服务自己的 `dry_run/dryRun` 会访问接口，与全局参数不是一回事。

对完整命令执行 `--dryrun`，检查请求内容和业务输出；失败就修正后重做。干跑与正式调用分开执行，不能在同一条无条件命令中紧接正式调用，也不能靠管道末端成功掩盖前面的错误。

用户确认的是已展示的具体配置、费用与批次顺序。正式命令只移除 `--dryrun`。规格、区域、AZ、镜像、网络、磁盘、数量、计费方式、周期或操作改变时，重新核验、询价、干跑和确认。

## 创建失败后

立即停止后续写入，保留错误码及请求对应关系，转为只读排查；不要循环更换规格、镜像或 AZ 试买，不自动回滚。仅对确有依据的新方案重新走完整流程。

请求超时或结果不明时，先查询订单／任务／资源状态，避免重复创建。返回任务或订单编号只代表已受理，继续只读查询后再报告最终状态。批次分别列出成功、失败、未执行和仍待核实的项目。

`Ecs.0016` 的公测权限、`Ecs.0019` 的规格下线等按实际错误解释；`Ecs.0707` 仅凭“产品不存在”不能确定网络或站点是根因。

## 退订和停止使用

不生成或执行退订 CLI/API，也不以本地干跑代替控制台预览。

- 包年／包月：华为云控制台 → 费用中心 → 订单管理 → 云服务退订；若入口显示“退订与退换货”，从该入口进入。
- 按需：引导到对应服务控制台，在备份后自行删除；本技能不代为删除。

提交前提醒用户备份或迁移数据，并核对账号、资源、关联资源、退款金额、手续费及退款去向。具体以控制台展示及[官方退订规则](https://support.huaweicloud.com/usermanual-billing/unsubscription_topic_2000010.html)为准。
