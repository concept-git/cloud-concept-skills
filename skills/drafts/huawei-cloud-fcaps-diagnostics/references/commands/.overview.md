# commands

本目录是华为云 FCAPS 诊断技能的命令契约库，按故障、配置、计量计费、性能、安全和共享查询组织，再按 hcloud、Linux、Windows 与可选 Kubernetes 区分事实所在环境。它用于从已知问题或完整命令 ID 定位操作、直接观测、输入依赖与执行约束，覆盖云资源、主机及集群；场景步骤、工具条件和参数映射分别由相邻资料提供。目录中也包含变更、扫描和主动采集，选读时须核对实际作用与授权。

## 目录覆盖情况

直接内容子项共 6 个，均为子目录；已完整阅读其中的 23 份 Markdown 分册，未抽样。本层 L0/L1 摘要不计入内容子项；L2 保留原位，下级目录不另建摘要。阅读不表示命令已在当前环境验证。

## 快速导航

- 想取得哪类事实？
  - 启动、失败事件、日志或已有任务结果 → [故障分册](#fault)，F、失败阶段。
  - 对象状态、网络路径或资源关联 → [配置分册](#configuration)，C、配置与关系。
  - 实际用量、账单或订购状态 → [计量计费](#accounting)，A、BSS。
  - 延迟、负载、CPU、内存或 I/O → [性能分册](#performance)，P、指标与有限采样。
  - 权限拒绝、告警、规则或异常访问 → [安全分册](#security)，S、策略与观测。
  - 身份、区域、审计或跨类别日志 → [共享查询](#common)，作用域与发现。
- 已选类别 → 云侧读 hcloud，主机或集群读对应环境；计费仅有 hcloud。
- 已知完整 ID → 直接搜索分册；缺少输入 → [参数与资源映射](../helpers.md)；需要操作步骤 → [场景概览](../recipes/.overview.md)。

## 详细说明

### [accounting](accounting/)

[云侧计量计费](accounting/hcloud.md)包含 BSS 成本、账单、资源消费、订单、余额、资源包，及 LTS 流量与 WAF 套餐。按账号站点和帮助选择区域；BSS 时间粒度是枚举。主机利用率不能替代账单，LTS 开启超额采集会改变配置。

### [common](common/)

[hcloud](common/hcloud.md)集中定义 IAM 账号／项目／区域发现、EPS 企业项目、CTS 事件和 LTS 日志，供其他类别复用。CTS 在线窗口为近 7 天，LTS 仅查已接入日志。[Linux](common/linux.md)读取发行版、内核、身份；[Windows](common/windows.md)读取 OS 与 PowerShell；[Kubernetes](common/kubernetes.md)只读本地 current-context，不证明集群可访问。

### [configuration](configuration/)

[云资源配置](configuration/hcloud.md)覆盖 ECS、EVS、IMS、CBR、资源发现、Agent、日志与通知；ACTIVE 仅表示平台状态。[网络配置](configuration/hcloud-network.md)覆盖 VPC、安全组、路由、DNS、EIP、ELB、ER、NAT、CC、VPCEP、VPN，只查实际路径。云盘、网卡和子网按 Helper 绑定，不混用设备路径和不同类型 ID。

[Linux](configuration/linux.md)涵盖服务、设备、挂载、地址、路由、参数与时间源；[Windows](configuration/windows.md)涵盖服务、磁盘关联、网卡、连接、计数器和驱动；[Kubernetes](configuration/kubernetes.md)涵盖节点、Pod UID、PVC/PV、StorageClass、EndpointSlice。配置正常不证明业务可用。

### [fault](fault/)

[云侧故障](fault/hcloud.md)包含告警、计划事件、控制台日志、任务及诊断结果，也含重启、恢复和脚本执行；须核对最终状态。COC 创建诊断会安装 Holmes 并采集数据，依赖 UniAgent 在线和采集授权。

[Linux](fault/linux.md)包括服务／内核日志、DNS、ICMP、逐跳探测、已删除但仍打开的文件与元数据 HTTP 状态；[Windows](fault/windows.md)包括事件、服务、DNS、TCP 和 PID 服务关联；[Kubernetes](fault/kubernetes.md)包括 Pod 事件、描述及当前／前一容器日志。留意保留期、权限和主动探测条件。

### [performance](performance/)

[云侧性能](performance/hcloud.md)连接 AOM、APM、CES 指标与调用链，以及容量、规格和云盘性能操作。CES 指标用毫秒，告警另用 ISO 8601。[Linux](performance/linux.md)涵盖 CPU、内存、进程、I/O、容量、inode、网卡、线程与连接跟踪；抓包、strace、perf 属于条件采集。[Windows](performance/windows.md)使用已发现的计数器、进程及网卡统计；[Kubernetes](performance/kubernetes.md)依赖 metrics API。对齐对象、时间和口径，缺指标不表示零使用。

### [security](security/)

[云侧安全](security/hcloud.md)涵盖 IAM、访问分析、CFW、DDoS、WAF、合规和 SecMaster；[主机安全](security/hcloud-host.md)聚焦 HSS 资产、Agent、告警、漏洞、基线、扫描与处置。只读已有状态时用 CFW `sync=0`、HSS `refresh=false`；HSS GET 基线接口也会启动检测。

[Linux 安全](security/linux.md)查询登录、防火墙、CPU 缓解和包文件差异；[Windows 安全](security/windows.md)查询有效防火墙、ACL 与本地账号组；[Kubernetes 安全](security/kubernetes.md)查询 NetworkPolicy 和当前身份的指定权限。规则声明、告警或文件差异需与实际命中证据分开判断。

契约四列为操作／模式、观测、输入及来源、约束。hcloud ID 保留服务／操作／版本，系统 ID 区分环境／模式；一个模式只定义一次。帮助见[工具概览](../tools/.overview.md)，执行见[主入口](../../SKILL.md#通用规则)，依据见[官方主题](../documents/huaweicloud.md)。
