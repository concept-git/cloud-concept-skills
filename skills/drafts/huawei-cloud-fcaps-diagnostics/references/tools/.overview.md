# tools

本目录说明华为云 FCAPS 诊断技能使用 hcloud、Linux、Windows 和可选 Kubernetes 时的工具条件、帮助发现、目标确认与执行要求。它用于首次使用工具、环境变化或命令选项不匹配时，判断现有通道和能力是否适用，再进入对应类别的命令契约。各说明保留作用域、输入格式、错误判断、采样和验证范围，避免把工具存在、本地配置有效或会话连通误当成目标查询已经成功。

## 目录覆盖情况

直接内容子项共 4 个，均为 Markdown 文件，已全部阅读，未抽样，无下级目录。本层 L0/L1 不计入内容子项。业务契约保留在 commands；验证记录仅描述限定的历史环境，不代表当前目标可用。

## 详细说明

### [hcloud](hcloud.md)

说明已配置的华为云 KooCLI，明确它与其他厂商同名工具的区别。首次构造调用查询 `hcloud Service Operation/version --help`，同版本帮助可以复用；操作版本与 HTTP 路径版本可能不同。作用域由已确认的 profile、region、IAM project、目标资源和时间窗决定，IAM project 与企业项目分别处理。

入口表区分版本／配置读取与配置修改、日志设置、缓存和 CLI 更新。`configure test` 仅查格式，认证看 API 响应；零退出码也要查错误对象。JSON 前仅剥离已识别的升级提示，未知前缀报错。数组用编号参数，分页、枚举和时间按帮助。

诊断选项说明 debug 仍执行原操作，dryrun 跳过业务 API 但可能读取元数据或项目，query／output 不改变服务端范围，waiter 轮询前应确认原操作只读。同步、检测、安装、消息发送或登录地址生成按实际影响判断，不能仅按 GET／POST 分类。已有任务查询最终结果；资源衔接由 Helper 处理。末尾连接各 hcloud 分册，不复制业务契约。

### [Linux](linux.md)

要求在目标主机读取 OS／内核，以工具帮助和版本确认选项兼容；systemd、procps、iproute2、util-linux、sysstat 分别核验。RPM 与 Debian 按发行版选择，缺工具记为缺口，不自动安装。接口、服务、进程和路径都属于当前目标；PID 可重用，云盘 ID 不等于设备名。

本机或 SSH 核对主机、账号、端口及主机密钥，在目标中执行并保留状态与错误。采样限定次数或时长。历史实测仅覆盖 Ubuntu 24.04，其他发行版重新核验。

### [Windows](windows.md)

从目标 Windows 会话的 PowerShell 版本、Get-Command 和 Get-Help 核对能力，管理机上有 PowerShell 不证明目标模块可用。cmdlet 使用命名参数与对象属性，错误按 ErrorAction Stop 处理；原生 exe 查自身帮助并检查 LASTEXITCODE。时间窗明确时区，计数器路径从目标发现，不硬编码英文路径。

服务名与显示名、磁盘编号与 EVS ID 分别处理；无匹配记录、权限错误和远程会话连通分别判断。现有契约仅在线查询，离线挂盘、加载注册表或修复另核授权。文中说明尚无 Windows 实测，首次使用须在适用目标验证；各 FCAPS 分册入口按需要读取。

### [Kubernetes](kubernetes.md)

这是可选环境，使用已有 Kubernetes API 通道，先查客户端版本和所选子命令帮助，再确认目标 context 与权限。每次集群查询显式指定 context，命名空间对象另指定 namespace；节点、PV、StorageClass 属于集群级对象。Pod 记录 UID 与容器名，同名对象可能已重建。

当前契约不含 exec 或调试容器；修改 kubeconfig、创建资源和安装组件需要另核影响与授权。通用 kubectl 不要求 GKE 前置步骤，CCE 的认证、CSI、网络插件及指标能力按实际集群核验，本地 kind 结果不代表 CCE。top 依赖 metrics API，缺指标不能报零。末尾链接共享、配置、故障、性能和安全分册，执行仍遵守[主入口规则](../../SKILL.md#通用规则)。
