## 详细说明

### [华为云文档指引](huaweicloud.md)

这是一份条件式参考导航，不复制官方操作步骤或命令。各 FCAPS 表格将“何时读取”与“官方来源”“关联契约”对应，跨类别主题共用来源。OS、地域、版本和产品类型决定是否适用，不能把标题相似当作同一现场原因。

故障主题覆盖 Linux 逐跳探测与磁盘空间、Windows 元数据路由、ECS 错误码／状态、LTS 搜索方式、COC 深度诊断、独享 ELB 健康检查、CCE 节点和 CBR 云盘恢复。LTS 控制台语法不能直接充当 API 参数；COC 要先核 OS、UniAgent 和采集影响；恢复须核停机、挂载及覆盖条件。

配置主题连接云盘与设备映射、CentOS 7 DHCP／NetworkManager、Windows virtio 驱动，以及安全组连接跟踪、流日志和 DNS 生效。性能主题进一步关联设备／进程 I/O、内存分配、线程、连接跟踪、CPU 缓解、CES 采样、EVS 规格与 EIP 事件；文档中的原因不能直接视为当前根因。

计量计费主题聚焦模式区别、故障状态计费和按资源查账单，金额仍以实际账单为准。安全主题连接 Linux 防火墙、CTS 事件缺失与账号查询、IAM 权限和 HSS 防护状态；未检测不等于无风险。独享 ELB 来源标明国际站，CCE 指引仅适用于 CCE，其他 Kubernetes 环境须使用对应平台来源。

### [官方文档读取规则](reading.md)

规定按需定位和核对正文：已知链接直接读取，否则从主题选择，未覆盖再搜索官方来源。优先使用页面或 llms.txt 提供的 Markdown，失败后读取同文档 HTML；两种格式按同一文档身份处理。须核对 ID、标题和实际正文，HTTP 200、后缀、登录页、验证页或页面空壳都不能证明取得内容。

读取时确认产品、系统、区域、版本和场景，记录官方 URL 与读取日期。失效链接按标题或 ID 在同一官方来源重找，找不到就说明缺口；断网只使用环境已配置的同 ID 归档并注明日期。文档与命令不一致时保留版本和差异，复核后使用；原文操作需要另核授权，现场结论仍需当前证据。

来源说明保留 2026-10-21 归档快照和 2026-10-22 补充指引的历史核验范围，日期不保证链接当前有效。官方原文、图片、缓存与读取记录保存在技能外，具体路径由环境提供。主题导航不承担事实查询或缺参解析；进入执行阶段继续使用命令契约、工具说明与 Helper。
