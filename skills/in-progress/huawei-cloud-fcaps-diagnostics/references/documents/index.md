# 官方文档入口

- 按需查阅。需要核对规则、解释异常或补充依据时再查文档，已有可靠答案或适用命令可直接使用。
- 直接定位。已知官方链接就读正文，否则先查[主题指引](huaweicloud.md)，未覆盖时搜索[文档索引](catalog.jsonl)，只读命中项。索引仅含 id、title、section、url。
- 核对正文。优先读页面或 llms.txt 提供的 Markdown，失败后读同文档 HTML。核对 ID、标题和正文，HTTP 200 或文件后缀不能证明成功，登录页、验证页和空壳不算正文。两种格式共用一个条目。
- 核对适用条件。确认产品、系统、区域、版本和场景，记录官方 URL 与读取日期。现场结论须有当前证据支持，文档中的操作须另核授权。
- 回到执行入口。执行命令查 [FCAPS 地图](../commands/index.md)，缺少输入查[参数与资源映射](../helpers.md)。
- 如实处理缺口。失效链接按标题或 ID 在同一官方来源重找，找不到就说明缺口，继续其他检查。断网可读环境已配置的同 ID 归档，并注明日期。
- 保留冲突。文档与命令条目不一致时记录版本和差异，复核后再使用，不直接覆盖已有命令。
- 归档放在技能外。路径由环境提供，原文、图片、缓存和读取记录均保存在技能外。
